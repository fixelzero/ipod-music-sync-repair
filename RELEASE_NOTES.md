# Suggested GitHub release: v0.6.1 (case-study toolkit)

**Scope:** Bundled V4–V6.1 workflow scripts and documentation. This version label is a packaging label; it is not evidence of a formally tested production release.

### Highlights
- Finder error-to-playlist batch workflow (V4)
- Read-only HLS inventory and conservative classification (V5.1/V5.3.2)
- Full-library metadata matching and opt-in playlist generation (V6)
- Best-effort ambiguous-track review (Review 03)
- Detailed repair journal, safety guidance, troubleshooting, and historical changelog

### Important
- No media deletion scripts are included.
- Some scripts use fixed report filenames and counts from the documented user's library; adjust for your own data.
- Final iPod sync after the 327-package cleanup has not been independently verified.
- No real personal logs or library CSVs are distributed.
